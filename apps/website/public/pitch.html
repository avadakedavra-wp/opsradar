  • Fixing means: find the source repo, edit the manifest, open a PR. Every time.

The gap between "what's wrong" and "the fix" is human, slow, and on-call at 2am.

Local-first. Least-privilege.

No SaaS, no cloud. Cluster data never leaves your machine.

Stack

Go API + Next.js dashboard + SQLite. One-command install.

Read-heavy

Safe by default
