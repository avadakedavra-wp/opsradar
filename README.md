# OpsRadar

> Kubernetes Operations Intelligence powered by Bob Shell AI

[![IBM Bob 2.0 Hackathon](https://img.shields.io/badge/IBM%20Bob%202.0-Hackathon%202026-blue)](https://github.com/avadakedavra-wp/opsradar)

See [docs/README.md](docs/README.md) for full documentation.

## Quickstart

```bash
git clone https://github.com/avadakedavra-wp/opsradar.git && cd opsradar
cp .env.example .env   # edit BOB_BIN, GITHUB_TOKEN, GITHUB_REPO
docker compose up
```

Open **http://localhost:3000**
